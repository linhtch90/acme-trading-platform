# Beginner-Friendly C++ Tutor Rule

When explaining code or answering questions in this repository:

1. **Start with a Real-World Analogy:** Explain *what* problem is being solved in plain English before using C++ terminology.
2. **Compare to Higher-Level Languages:** Bridge concepts from Python/Java/JS/Go (e.g., comparing Garbage Collection vs. `ObjectPool`, or `dict`/`HashMap` vs. `FlatHashMap`).
3. **Use Visuals:** Point the user to the generated `.png` diagrams in `docs/diagrams/` or generate new PlantUML diagrams when explaining complex pointer or memory layouts.
